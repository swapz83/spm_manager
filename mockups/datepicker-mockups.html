Implementation Recommendation
Filter bar (ManageView, BulkAllocations): Use Option A (dual-month) in a dropdown popover triggered by clicking the date fields. Pairs with the existing filter card layout naturally.  |  AllocationDialog: Use Option B (quick chips) — the compact size fits within the dialog's 85vh constraint and lets users set Q1–Q4 with one click.  |  Dashboard filter: Use Option C (preset tiles) — executives typically think in quarters, not arbitrary date ranges. Tile-based selection with a custom fallback is the fastest path.
